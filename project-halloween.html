Personal Project

Arduino Halloween Light Show

Northeastern University — General Engineering

Role Designer & Builder
Tools Arduino, C++
Hardware LEDs, speaker, photoresistor
Song Peer Gynt

Overview

For my General Engineering class, I was tasked with building a circuit involving a speaker, LED lights, and a Halloween theme. In service of the assignment, I built a Halloween light display circuit with an Arduino controlling several LEDs to activate in sync with a note played from a speaker, so that the lights would change in cadence with the music, to create a light show with music.

How it works

After writing the Arduino C++ code and uploading it to the Arduino, the entire circuit was placed in a box so that it could be discovered. The circuit was designed with a photoresistor to measure light exposure, so that it would be aware whether the box had been opened, and if so, how much. This would determine which frequencies to play, and which pattern of lights to display. The notes were picked out, and their frequencies given to the speaker to play, along with how long they should be held for, and which lights should be on for that corresponding time duration. Having selected specific frequencies to play in certain time intervals, I was able to have the speaker play Peer Gynt.
